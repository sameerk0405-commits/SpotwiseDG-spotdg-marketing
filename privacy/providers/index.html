Service providers

These are the companies that help us run the Service and may receive personal data for that purpose.

  • Google, for sign-in.
  • Supabase, which hosts our database in the United States.
  • Railway, which hosts the dashboard.
  • Netlify, which hosts the website.
  • Anthropic, which processes Ask query text.
  • Formspree, which receives and stores website form submissions.
  • Plausible, which provides website page statistics.
  • OpenFreeMap, OpenMapTiles and OpenStreetMap, which serve map tiles to your browser.
  • Gmail, which carries alert emails to our founders. These alerts can contain the attempted email addresses and IP addresses from rejected sign-ins.
